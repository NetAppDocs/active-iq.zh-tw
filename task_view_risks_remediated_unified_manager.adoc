= 在Digital Advisor中查看操作風險，並使用 Unified Manager 或 Ansible Playbook 進行緩解。
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以透過檢視行動和風險來分析儲存系統、並使用Active IQ Unified Manager 《不受影響的戰術》或《不受影響的戰術》來減輕風險。

video::XusFvXM7h-E[youtube,width=848,height=480]
.步驟
. 在儀表板上選擇 *View All Actions*。
. 選擇 *Actions* 以檢視與操作相關的風險，選擇 *Risks* 以檢視所有風險，或選擇 *Affected Systems* 以檢視需要注意的系統。
+
如果您可以使用Active IQ Unified Manager 不確定的功能來減輕風險、請使用 image:spanner.png["西班牙文"] 圖示會反白顯示、如果您可以使用Ansible教戰手冊來減輕風險、請參閱 image:update_ansible.png["更新Ansible"] 圖示會反白顯示。



[cols="50,50"]
|===
| 使用Unified Manager降低風險 | 使用Ansible教戰手冊降低風險 


 a| 
. 選擇 image:spanner.png["西班牙文"] 圖示。
. 選擇「修復」以啟動 Active IQ Unified Manager。
. 選擇「安裝」以安裝 Active IQ Unified Manager 9.7 或更高版本，即可使用「修正」選項。
. 選擇 *升級* 以升級至 Active IQ Unified Manager 9.7 或更高版本，即可使用 *修正* 選項。

 a| 
. 選擇 image:update_ansible.png["更新Ansible"] 圖示。
. 選擇 *Download* 以下載 AFF 和 FAS 韌體 Ansible Automation 套件。


|===

NOTE: 使用*修復*選項和可執行教戰手冊功能時、需要簽訂一份不完整或不完整的合約。SupportEdge Advisor SupportEdge Expert
