= 檢視 Value Insights 儀表板
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
檢視 Value Insights 儀表板，以存取 ONTAP 系統的健全狀況、節省成本、穩定性和安全性資訊。

.步驟
. 選擇「顧客成功 > 價值洞察」。
. 在「整體健全狀況及 NetApp 如何提供協助」區域，您可以檢視 ONTAP 系統的整體健全狀況評分（以百分比表示）。此評分以 KPI 為基礎。
+
** 選擇「更多建議」以查看所有 KPI：
+
[cols="2*"]
|===
| KPI | 說明 


| 針對永續營運的建議 | 為永續系統運作提供建議。 


| 解決叢集上的安全強化風險 | 評估每個系統相關的安全性風險。 


| 規劃韌體和系統檔案更新 | 檢查系統是否執行最新韌體並提供更新建議。其中包括用於規劃韌體更新的詳細檢視。 


| 檢視技術更新選項（EOL） | 評估技術更新的必要性。 


| 在叢集上啟用 AutoSupport （ASUP） | 監控叢集上的 AutoSupport（ASUP）狀態。 


| 計畫升級至最新推薦的 ONTAP 版本 | 評估系統軟體版本並提出更新建議。 


| 評估儲存擴充方案 | 評估目前儲存效率和儲存擴充需求。提供未來容量需求的預測。 


| 合約續約 | 評估支援合約的狀態，並提供續約建議。 


| 主動監控以防止非計劃性叢集停機 | 提供各叢集的計劃外停機次數。 
|===
** 選擇 *How is this calculated?* 以查看具體 KPI 計算方法。向下捲動以查看系統詳情，包括：滿分、部分分數和零分。


. 選擇「NetApp 已實現的節省和穩定性」以檢視您的投資報酬率 (ROI) 的詳細資訊。
+
[cols="2*"]
|===
| 功能 | 說明 


| image:edit_icon.png["編輯按鈕的影像"] | 選擇以編輯每 TiB 的成本或支出。 


| 儲存效率值 | 點選以開啟 ROI 儀表板。 


| 儲存正常運行時間值 | 檢視數值並選擇系統編號值以了解更多詳細資訊。 


| AutoSupport ID | 如果適用，請選擇檢視導致停機或停電的問題或事件。 


| 已發現並預防的風險 | 選取以檢視過去 3 個月的相關資料。 


| 檢視健全狀況歷程記錄 | 選取以查看摘要檢視。 


| 風險值 | 選擇每個風險值，即可存取過去 3 個月的相關資料。 
|===
. 選擇「安全與未來規劃」區域以檢視有關安全性的資訊。
+
[cols="2*"]
|===
| 功能 | 說明 


| 安全性威脅已消除 | 選取以檢視安全性詳細資料。 


| 安全性問題已解決 | 選取以開啟健全狀況歷史記錄頁面。 


| 自動韌體更新 | 選取以開啟韌體類型和升級詳細資料。 


| 自主勒索軟體保護 AI/ML 模型 | 選取以開啟模型的詳細資料。 


| 提高效率帶來的預計節省  a| 
** 選擇「預測儲存效率節省」旁邊的 image:edit_icon.png["編輯按鈕的影像"] 圖示，即可編輯每 PiB 的成本。
** 選擇儲存容量餘裕百分比，開啟容量和效率頁面。
** 選擇 *Lifecycle planning*。
** 選擇工具值以開啟對應的 ONTAP 詳細資料頁面：系統重新整理、儲存擴充和支援續訂。
+

NOTE: 此功能僅適用於 ONTAP 系統，不適用於 Cloud Volumes ONTAP、ONTAP Select、StorageGRID 或 E 系列等平台。



|===
. 選擇「如何最大化基礎架構價值」以檢視有關作用中功能和可用最佳化的資訊。
+
** 選擇 *Active capabilities* 以檢視系統詳細資訊。
** 選擇 *Available optimization opportunities* 以檢視建議。
