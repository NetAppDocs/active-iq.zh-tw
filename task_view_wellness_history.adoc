= 在Digital Advisor中查看您的儲存系統風險歷史記錄
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以查看過去三個月內發生的儲存系統風險，以便了解這些風險隨時間推移的發展。

這些風險分為四類風險：*未解決*、*新增*、*已解決*及*已確認*。它們以不同的色彩表示。這些風險的摘要會透過*風險歷程*圖表來呈現。

.步驟
. 在儀表板的「健康」窗格中，選擇「檢視所有動作」。
. 選擇 *Wellness History*。
. 在「風險歷史」圖表中，選擇要檢視風險歷史的類別。
+
將滑鼠停留在彩色長條圖上，即可檢視各類別風險的數量資訊。選擇相應的風險類別後，相關資訊將顯示在「風險資訊」表格中。

+
您也可以在Excel工作表中下載風險摘要。
